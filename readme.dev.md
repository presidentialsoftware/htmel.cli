Since this is the CLI repository, the key question is whether you want to install the command-line tool globally on your computer or use it locally in another Node.js project.

## Install `htmel.cli` without publishing to npm

### Option A — Install the CLI globally from GitHub

Bash

```
npm install -g git+https://github.com/presidentialsoftware/htmel.cli.git
```

This installs directly from GitHub without publishing to npm. If the repository defines a `bin` entry in `package.json`, npm can expose the CLI command globally.

### Option B — Install it locally for development

Bash

```
git clone https://github.com/presidentialsoftware/htmel.cli.git
cd htmel.cli
npm install
```

If it has a build script, run:

Bash

```
npm run build
```

To make its CLI command available to your current project without publishing, use:

Bash

```
npm link
```

You can then run the executable specified by the package's `bin` field.

### Option C — Test the package as a real installation

From the CLI repository:

Bash

```
npm install
npm pack
```

This generates a `.tgz` package archive. Install that archive into another project:

Bash

```
npm install /path/to/htmel.cli-1.0.0.tgz
```

Replace the filename with the actual archive name generated by `npm pack`. This method is useful for testing packaging and executable configuration before publishing.
