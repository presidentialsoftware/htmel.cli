Import cards

Paste cards in a simple format, one per entry: Front = Back. For example, Capital of France = Paris. Continuation lines are attached to the previous entry. You can also import a JSON backup.

Tip: this app is topic-neutral. Use it for vocabulary, math, facts, questions and answers, or anything else you want to study.

Import format

  • Each entry begins with Front = Back.
  • Use one entry per line; continuation lines are appended to the previous card's back.
  • Duplicate fronts are allowed.
  • JSON exports can be used to back up or transfer one deck or all decks.
Decks and study progress are saved in this browser on this device. Export all decks as JSON to back them up or move them to another browser or computer.
